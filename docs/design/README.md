## 实现中不可绕过的约束

- 身份从登录态获取；维护资格与正文阅读权限分开。
- MySQL 决定权限及生效构建，搜索引擎只是可重建副本。
- 搜索预过滤、内容外发前复核、最终返回与历史读取复核缺一不可。
- 原文、生成表示、检索结果、真正发送的上下文、答案引用分别记录。
- 所有模型调用，包括嵌套工具、OCR 后视觉描述、评估和重试，进入统一预算。
- 实验和测试物理隔离；先使用模拟材料，不自动读取公司正文。
- 验收记录尚不存在，不能从设计完成推导系统已经可用于简历成果展示。
