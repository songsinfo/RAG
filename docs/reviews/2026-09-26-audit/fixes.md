## 部署前提

1. 现有 MySQL 库先审查并执行 `deploy/migrations/20260926_model_call_owner.sql`。该迁移允许 Search 调用仅归属于租户，同时禁止一条调用同时归属于 QA 和任务。新库使用更新后的 `docs/design/schema.sql`。
2. API 和 worker 配置 `RAG_MODEL_PRICES_CNY`：JSON 对象，以 `chat-main`、`judge-main`、`embedding-main`、`rerank-main` 及启用的 fallback 别名为键；每项必须包含非负 `inputPerMillion`、`outputPerMillion`，单位为人民币/百万 token。请使用实际供应商费率，不要使用示例虚构价格。别名对应的 `cfg-model-<alias>` 配置记录也必须存在。
3. `RAG_MONTHLY_BUDGET_CNY` 默认 100；配置实际月度预算。文本 UTF-8 字节数加协议余量用于保守预留；真实返回 token 另行记录。超时/失败可能已计费，故预留不自动返还。此机制不提供供应商账单结算，也不保证供应商最终收费；非 token 定价模型需先确认费率映射适用。
4. 生产缺少价格会在外发前拒绝调用；旧配置如果启用未实现策略，需先关闭这些开关。离线测试使用替身，不需要价格。
